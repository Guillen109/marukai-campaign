# Márukai: Clash of the Yayas — public campaign page

Standalone static site for GitHub Pages. No backend or accounts. The static site does not store personal data;
new voluntary newsletter requests can be forwarded by an external form service.
No commerce or analytics cookies are included.

The ONLY external destinations are the game's approved pages on itch.io,
Kickstarter and Game Jolt. This repo includes an optimized version of the
project's previously approved official Game Jolt cover art.

This landing site is separate from the Macuto Imperium app and from the
dynamic campaign signup service. Optional email-request forms are handled
by FormSubmit.co, and must be activated and verified independently. The
private Macuto shop is never exposed.

The published site is https://guillen109.github.io/marukai-campaign/
The `source` URL parameter is a share label, not a server analytics service.

## Languages and discovery

- Spanish: / (index.html)
- English: /en.html
- Both pages include canonical, hreflang, Open Graph, Twitter image, and
  JSON-LD VideoGame metadata based on the game's actual itch.io listing.
- robots.txt and sitemap.xml provide discovery URLs.

## Promotion materials

- press-kit.md: ready-to-review ES/EN descriptions, short posts and hashtags
- marukai-qr.png: scannable QR code pointing to the public campaign homepage
- marukai-social.jpg: 1200x630 social preview image

The static site has no account login, local mailing list, server-side attribution,
or automatic publishing. The new signup request uses an external forwarding form. Sharing link parameters are labels, NOT measured
conversion events. Three official outbound links only.

## V1.7 — voluntary email update request (11 Nov 2026)

The two public landing pages now link to `suscribirse.html` and `subscribe.html`.
New bilingual opt-in request pages include a required consent checkbox, an
interest selector, an anti-bot honeypot, informational privacy pages, and
acknowledgement pages. Requests are sent to the creator's Gmail using the
third-party hosted service FormSubmit.co, NOT to Macuto's local database.
First-time use of FormSubmit.co requires email activation by the creator.

**Important:** This is a request inbox, not a fully verified double-opt-in
newsletter platform. Do not send marketing until email ownership/consent is
confirmed, sender identification and unsubscribe handling are configured, and
any applicable requirements are satisfied. A public form alone does not
prove delivery or subscription. Website visitors still need no account.

The published game builds, marketplace listing data, and Macuto's private
store, billing, and authentication code have not been changed.
