**Short description (English):**
MARUKAI: Clash of the Yayas is an independent 3D fighting game inspired by Taíno-Caribbean aesthetics and storytelling. We are inviting Windows players to try the current free build and help us improve controls, combat readability, performance, arenas, audio and game stability. Honest critical feedback is welcome. No purchase or payment is required.

**Playtest name:** MARUKAI — Public Windows Combat & Stability Playtest 01

**Testing format:** Public playtest using existing itch.io download; no re-upload required.

**Who we want:** Windows PC players who enjoy fighting games; both newcomers and experienced gamepad users.

**Estimated session:** 15–30 minutes, voluntary and unpaid.

**Goals (please test):**
1. Download and launch; check that the available characters and worlds load.
2. Try movement, keyboard and a controller if available.
3. Play Arcade and local Versus if the build offers them.
4. Test combos, dashes, blocking and special moves.
5. Watch for camera trouble, floating characters, clipping and collision problems.
6. Report FPS issues, audio duplication, crashes or loading problems.

**Feedback questions:**
1. Did the game start on the first attempt? If not, what error appeared?
2. Which fighter and mode did you choose?
3. Was anything confusing about the controls?
4. Were hits, combos and character reactions clear and satisfying?
5. Did you experience frame drops, crashes, missing arenas or sound issues?
6. What one change would improve the game most?
7. Would you play again? Why or why not?

**How to report bugs:** Include Windows version, CPU/GPU/RAM, input device, build date, character/mode and reproduction steps. Optional screenshots and short gameplay clips. Never submit sensitive logs or private information.
